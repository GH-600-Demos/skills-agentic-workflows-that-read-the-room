## Recent updates worth watching

Source: [GitHub Changelog](https://github.blog/changelog/), October 2026.

- **Stacked pull requests are generally available.** Split a large change into small, independently reviewable pull requests that merge together. [Changelog, Oct 6](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available)
- **Async merge API is generally available.** The recommended way to merge pull requests programmatically, and the only merge API that supports stacks. [Changelog, Oct 1](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available)
- **GitHub Actions workflow lockfiles (public preview).** Pin the exact commits your workflows run, even if a tag or branch moves. [Changelog, Oct 14](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview)
- **Bulk migrate branch protections to rulesets.** Convert all of a repository's branch protection rules in one action. [Changelog, Oct 20](https://github.blog/changelog/2026-10-20-bulk-migrate-branch-protections-to-rulesets-for-a-repository)
