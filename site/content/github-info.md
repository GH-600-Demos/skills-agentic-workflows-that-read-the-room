## Recent GitHub updates worth watching

- **Stacked pull requests are generally available** (Oct 6, 2026): break large changes into smaller pull requests that are reviewed independently and merged together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **Local sandboxing for GitHub Copilot is generally available** (Oct 7, 2026): commands run by Copilot in the CLI, the Copilot app, and VS Code Agent Host sessions get restricted access to files, network, and credentials. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/).
- **GitHub Actions workflow lockfiles in public preview** (Oct 14, 2026): keep tag or branch references in a workflow while running the exact commits you locked. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/).
- **AI Scan for pull requests is generally available** (Oct 15, 2026): code scanning findings for languages CodeQL doesn't cover, such as PHP, Shell/Bash, Terraform, and Dockerfiles. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available/).
