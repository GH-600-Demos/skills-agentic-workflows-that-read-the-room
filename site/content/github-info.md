## Recent updates worth watching

- **Stacked pull requests are generally available.** Split large changes into smaller pull requests that are reviewed independently and merged together. Source: [GitHub Changelog, Oct 6, 2026](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **GitHub Actions workflow lockfiles (public preview).** Lock the exact commits your workflows run, so a moved tag or branch can't silently change what executes. Source: [GitHub Changelog, Oct 14, 2026](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/).
- **Teach Copilot about your codebase.** A beginner guide to custom instructions, skills, custom agents, and MCP servers in the GitHub Copilot app. Source: [GitHub Blog, Oct 12, 2026](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/).
- **Continue a Copilot app session in VS Code.** Move an agent session without losing the conversation or code changes. Source: [GitHub Blog, Oct 19, 2026](https://github.blog/ai-and-ml/github-copilot/how-to-continue-a-github-copilot-app-session-in-vs-code/).
